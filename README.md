# odin-etch-a-sketch

## Project

Built as part of The Odin Project Foundations lesson [Project: Etch-A-Sketch](https://www.theodinproject.com/lessons/foundations-etch-a-sketch).

The goal was to build a sketchpad interface in the browser where users can draw by hovering over grid squares and create a new grid with a custom size.

## What I practiced

- Creating and removing DOM elements with JavaScript
- Using loops to generate a dynamic grid of squares
- Handling mouse events with `mouseenter`
- Using `event.target` to update the interacted grid square
- Adding event listeners to dynamically created elements
- Reading and updating CSS custom properties with JavaScript
- Using Flexbox to display a responsive square grid
- Collecting and validating user input from `prompt()`
- Separating behavior into focused functions
- Researching JavaScript and CSS concepts through documentation and search
